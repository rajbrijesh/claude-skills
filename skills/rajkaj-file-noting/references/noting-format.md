## 1. पत्रावली की बनावट और संदर्भ देने का तरीका

- **पत्र-व्यवहार भाग** (correspondence side): received letters and office copies of letters sent. Cite as `पृ.सं. 12/प.व्य.` or for a range `पृ.सं. 12-15/प.व्य.`
- **टिप्पणी भाग** (notesheet side): earlier notes and orders. Cite as `पृ.सं. 3/टि.`
- **पताका** (flag): a paper put up for reference. Cite as `पताका 'क'`, `पताका 'ख'` … in Hindi alphabetical order (क, ख, ग, घ …).
- If no file page number is visible, cite the PDF page as `(PDF पृ. 7)` and list it in the remarks so the user can correct it.
- Earlier orders on the notesheet are cited as: `पृ.सं. 4/टि. पर अंकित आदेशानुसार`.

Dates: `dd.mm.yyyy` (e.g. 05.10.2026). Amounts: `₹ 9.85 लाख` or `₹ 9,85,000/-`, matching the source.

## 2. टिप्पणी का साँचा

Paragraph numbers run continuously across sections. Section labels are plain lines (no markdown) because the note is pasted into an editor. The template below sits in a code block only to show its layout here; in the chat reply, write the note as ordinary paragraphs, not inside a code block.

```text
विषय : [विषय, जैसा पत्र में है या संक्षेप में]

संदर्भ : [प्रेषक] का पत्र क्रमांक [क्रमांक] दिनांक [दिनांक]

प्रकरण की पृष्ठभूमि
1. प्रकरण में [प्रेषक] के पत्र क्रमांक [क्रमांक] दिनांक [दिनांक] (पृ.सं. __/प.व्य.) द्वारा [क्या चाहा गया / क्या भेजा गया] है।
2. [आगे का पत्र-व्यवहार, कालक्रम में, हर तथ्य के साथ पृष्ठ संदर्भ]

विचारणीय बिन्दु
3. [मुद्दा, कमी या विरोधाभास — एक बिन्दु एक वाक्य-समूह में]
4. [...]

नियम / परिपत्र स्थिति
5. [पत्रावली पर उपलब्ध या पूर्णतः निश्चित नियम/परिपत्र का उल्लेख, पृष्ठ/पताका सहित]
   अथवा: प्रकरण में नियम-स्थिति का परीक्षण आवश्यक है।

प्रस्ताव
6. अतः प्रस्तावित है कि [स्पष्ट प्रस्ताव]।

[समापन वाक्य]

                                                    (हस्ताक्षर)
                                                    [नाम]
                                                    [पदनाम]
                                                    दिनांक : ____
```

Use only the sections that have content. If there is nothing under नियम / परिपत्र स्थिति, write the "परीक्षण आवश्यक" line rather than dropping the section, so the officer sees it was considered.

## 3. उद्देश्य के अनुसार मानक वाक्यांश

**प्राप्त पत्र का उल्लेख**
- प्रकरण में … के पत्र क्रमांक … दिनांक … (पृ.सं. __/प.व्य.) द्वारा … चाहा गया है।
- … द्वारा पत्र क्रमांक … दिनांक … (पृ.सं. __/प.व्य.) से … प्रेषित किया गया है।
- उक्त के क्रम में … ने पत्र दिनांक … (पृ.सं. __/प.व्य.) से अवगत कराया है कि …

**पिछली टिप्पणी या आदेश का उल्लेख**
- पृ.सं. __/टि. पर अंकित आदेशानुसार … को पत्र दिनांक … (पृ.सं. __/प.व्य.) प्रेषित किया गया था।
- पूर्व टिप्पणी पृ.सं. __/टि. अवलोकनार्थ संदर्भित है।

**तथ्य और कमियाँ बताना**
- पत्रावली पर उपलब्ध दस्तावेज़ों के अनुसार …
- प्रस्ताव के साथ … संलग्न नहीं है।
- पत्र दिनांक … में राशि ₹ … अंकित है, जबकि तखमीने (पृ.सं. __/प.व्य.) में ₹ … है। दोनों में भिन्नता है।
- … के संबंध में स्थिति स्पष्ट नहीं है।

**प्रस्ताव रखना**
- अतः प्रस्तावित है कि …
- यदि सक्षम स्तर से उचित समझा जाए तो …
- प्रकरण … को आवश्यक कार्यवाही हेतु प्रेषित किया जाना प्रस्तावित है।

## 4. समापन वाक्य कब कौन-सा

| स्थिति | समापन वाक्य |
|---|---|
| केवल सूचना, कोई निर्णय नहीं | अवलोकनार्थ प्रस्तुत है। |
| अधिकारी का निर्णय चाहिए | अवलोकनार्थ एवं आवश्यक आदेशार्थ प्रस्तुत है। |
| प्रस्ताव पर सहमति चाहिए | प्रस्ताव अनुमोदनार्थ प्रस्तुत है। |
| वित्तीय/प्रशासनिक स्वीकृति चाहिए | स्वीकृति हेतु प्रस्तुत है। |
| आगे के निर्देश चाहिए | आगामी निर्देशार्थ प्रस्तुत है। |

## 5. उदाहरण (काल्पनिक)

Illustrative only. Every name, number and date below is invented to show the shape of a good note; never carry any of them into a real note.

Situation: a Panchayat Samiti has sent a technical sanction proposal; the land availability certificate is missing and the cost differs between letter and estimate.

```text
विषय : ग्राम पंचायत [क] में सी.सी. सड़क निर्माण कार्य की तकनीकी स्वीकृति बाबत।

संदर्भ : विकास अधिकारी, पंचायत समिति [ख] का पत्र क्रमांक 1234 दिनांक 12.08.2026

प्रकरण की पृष्ठभूमि
1. प्रकरण में विकास अधिकारी, पंचायत समिति [ख] ने पत्र क्रमांक 1234 दिनांक 12.08.2026 (पृ.सं. 1/प.व्य.) द्वारा ग्राम पंचायत [क] में 250 मीटर सी.सी. सड़क निर्माण कार्य का तकनीकी स्वीकृति प्रस्ताव भिजवाया है।
2. प्रस्ताव के साथ तखमीना (पृ.सं. 2-6/प.व्य.), कार्य-स्थल का नक्शा (पृ.सं. 7/प.व्य.) और ग्राम सभा का प्रस्ताव दिनांक 02.07.2026 (पृ.सं. 8/प.व्य.) संलग्न हैं।

विचारणीय बिन्दु
3. पत्र में कार्य की लागत ₹ 9.85 लाख अंकित है, जबकि तखमीने के सार (पृ.सं. 6/प.व्य.) में कुल राशि ₹ 9.58 लाख है। दोनों राशियों में भिन्नता है।
4. कार्य-स्थल की भूमि उपलब्धता का प्रमाण-पत्र पत्रावली पर उपलब्ध नहीं है।

नियम / परिपत्र स्थिति
5. प्रकरण में नियम-स्थिति का परीक्षण आवश्यक है।

प्रस्ताव
6. अतः प्रस्तावित है कि विकास अधिकारी, पंचायत समिति [ख] से राशि की भिन्नता का स्पष्टीकरण एवं भूमि उपलब्धता प्रमाण-पत्र प्राप्त किया जाना उचित प्रतीत होता है।

प्रस्ताव अनुमोदनार्थ प्रस्तुत है।

                                                    (हस्ताक्षर)
                                                    [नाम]
                                                    [पदनाम]
                                                    दिनांक : ____
```

What makes it work: every fact has a page reference; the two problems are stated plainly with the figures side by side; no rule is cited because none is on file; the proposal says exactly what is being sought, as a proposal and not as an instruction.

## 6. किन शब्दों से बचें

These make a note read machine-written or padded:

- "यह ध्यान देने योग्य है कि", "उल्लेखनीय है कि" (बार-बार), "निष्कर्षतः", "संक्षेप में कहें तो"
- "अत्यंत महत्वपूर्ण", "व्यापक", "समग्र" without a reason
- "सुनिश्चित करें" in every paragraph
- Three adjectives in a row, or the same sentence shape repeated paragraph after paragraph
- Markdown in the note: no `**`, `#`, or bullet symbols. Use numbered paragraphs and (क), (ख) for sub-points.

## 7. भाषा का लहजा: सुझावात्मक, आदेशात्मक नहीं

A note is put up to a senior who decides. The writer proposes; the writer does not instruct. Orders in the writer's voice ("भिजवाएँ", "तुरंत करें") read as presumptuous when the note goes up the chain, and they also make the note look like an order that already carries authority. Use the forms below.

- पत्रावली पर उपलब्ध तथ्य बताते समय सीधे तथ्य लिखें: "पत्रावली पर … उपलब्ध नहीं है", "… में भिन्नता है"। इनमें कोई निर्देश नहीं होता।
- कार्यवाही को प्रस्ताव के रूप में रखें: "प्रस्तावित है कि …", "… किया जाना प्रस्तावित है", "… उचित प्रतीत होता है", "यदि सक्षम स्तर से उचित समझा जाए तो …"।
- कर्ता-रहित या भाववाच्य रूप चुनें ("प्राप्त किया जाए / प्राप्त किया जाना प्रस्तावित है"), आज्ञार्थक रूप नहीं ("प्राप्त करें", "भिजवाएँ", "सुनिश्चित करें")।
- समय-सीमा हो तो उसे तथ्य की तरह लिखें: "पत्र में … तक उत्तर चाहा गया है", न कि "शीघ्र कार्यवाही करें"।
- "आवश्यक है", "अनिवार्य है", "तत्काल" जैसे शब्द तभी रखें जब वे पत्रावली के किसी नियम या पत्र में स्वयं लिखे हों, और तब उसका संदर्भ दें।
- समापन वाक्य ("आवश्यक आदेशार्थ प्रस्तुत है") मानक है और अधिकारी से निर्णय चाहने का विनम्र रूप है; इसे बदलने की ज़रूरत नहीं।
